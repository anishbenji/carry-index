# Fabric notes: research and sources

Research behind the fabric reference pages in `design/materials/v1/` (written 23 Oct 2026).

- `<page>.md`: one file per page. Each lists the research files it draws on, the editorial decisions and corrections, the open questions, and every source, numbered as on the page.
- `research/`: the full research notes, one file per area. Every fact in them has a source URL, opened on 23 Oct 2026.
  - `hub-tests.md`: denier, weaves, coatings, laminates, test methods, glossary terms.
  - `nylon-polyester.md`: nylon (A), polyester (B), coatings and PFAS rules (C).
  - `laminates.md`: X-Pac (A), ECOPAK (B), delamination (C).
  - `uhmwpe-ultra.md`: the UHMWPE fibre and Challenge ULTRA.
  - `uhmwpe-others.md`: Graflyte (A), Dyneema composites (B), woven UHMWPE, gridstops and ALPAKA's fabrics (C).
  - `BRIEF.md`: the rules every research thread followed.
  - `series-credit.md`: credit and links for u/strandedvariable's deep-dive series.
- `factcheck/`: the independent fact-check of the built pages, with the brief it followed.

The deep-dive posts guided which topics to cover. Nothing was copied from them: no text, no tables, no images.
