# ADR-0003: The private app is called Kit Watch

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "B4: Private app name"

## Context

The private app replaces today's Kit Watch page and is seen only by its owner.

## Decision

The private app keeps the name Kit Watch.

## Consequences

The name appears only on the owner's own screens and in the code (`apps/kit`), never on the public site.

Decided 25 Nov.
