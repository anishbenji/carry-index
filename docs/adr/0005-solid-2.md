# ADR-0005: Solid 2 for both apps, built with a director thread in T3 Code

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "Stack"

## Context

Solid 2.0.0 was released on 17 Nov 2026. The architecture doc was written against rc.21.

## Decision

Solid 2 (2.0.x, exact pins) for both apps; built in T3 Code with a director thread.

## Consequences

Both apps use Solid 2.0.x at exact versions, upgraded only in dedicated pull requests. Solid 1 patterns and SolidStart are not used. Work runs as small pull requests from worker threads under a director thread with cross-model review.
