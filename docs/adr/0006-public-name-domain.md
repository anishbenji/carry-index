# ADR-0006: Public name Carry Journal on carryjournal.com

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "N12: Public name and main domain"

## Context

'The Carry Index' clashes with an existing carryindex.com. An older diagram mentioned mycarryjournal.com.

## Decision

The public site is called "Carry Journal" in one fixed form everywhere. carryjournal.com is the main domain; mycarryjournal.com, if owned, permanently redirects to it. "Carry Index" stays an internal name.

## Consequences

'Carry Journal' in one fixed form everywhere public. carryjournal.com is canonical; mycarryjournal.com, if owned, redirects permanently. 'Carry Index' stays internal (the repo, the project).

## Why

Accepted the recommendation (short, matches the domain; "The Carry Index" clashes with an existing carryindex.com).
