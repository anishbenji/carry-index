# ADR-0009: No affiliate links at launch

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "B8b: Affiliate links"

## Context

Affiliate links would weaken the trust position of an independent index.

## Decision

No affiliate links at launch. If any are added later, each is disclosed on the page that carries it.

## Consequences

No affiliate links in Release 1. Any added later is disclosed on the page that carries it.

## Why

Chose the cleanest trust position for launch.
