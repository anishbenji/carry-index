# ADR-0011: Release 1 scope and date: Saturday 28 Nov 2026

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "N10: Release 1 scope and date"

## Context

The owner wants the public site live and the private foundation in place within the week.

## Decision

Release 1 targets Saturday 28 Nov 2026 evening. Public site live: home, UHMWPE listing, 12 bag pages, fabric pages, about and sources, sitemap and 404, with every budget and gate in CI and the metrics beacon collecting from day one. Kit Watch foundation: Cloudflare Access sign-in, D1 schema and migrations, the import (dry run, then real), read-only item pages and search. Not in Release 1: carry logging in the new app, the publish flow, watchlist and alerts, review pages. Today's Kit Watch page stays the working tool. Cut scope, never quality; cut order: compare page, private search screen, fabric comparison page, live performance figures.

## Consequences

Public: home, UHMWPE listing, 12 bag pages, fabric pages, about and sources, sitemap and 404, every budget and gate in CI, metrics beacon from day one. Private: Access sign-in, D1 schema and migrations, the import (dry run then real), read-only item pages and search. Not in Release 1: carry logging, publishing, watchlist and alerts, review pages. Cut scope, never quality, in this order: compare page, private search screen, fabric comparison page, live performance figures.

## Why

Accepted as proposed.
