# ADR-0012: Go live on Saturday with unchecked airlines marked

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "N11: Go live on Saturday"

## Context

The earlier launch gate required every airline's cabin limits to be checked first. Field speed data and search indexing start only once the site is live.

## Decision

Go live on carryjournal.com on Saturday, indexed, with unchecked airlines marked as unchecked. This replaces the earlier gate that every airline's cabin limits be checked before launch.

## Consequences

The site goes live on carryjournal.com on Saturday, indexed. Airlines not yet checked are labelled unchecked in the widget. This replaces the earlier all-airlines-checked gate.

## Why

Real-visitor speed data and search indexing start only once the site is live.
