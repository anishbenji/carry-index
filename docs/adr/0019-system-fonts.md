# ADR-0019: System fonts only at launch

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "N4: Fonts"

## Context

Web fonts cost bytes and can shift layout.

## Decision

System fonts only at launch (0 KB of web fonts). A brand font may be added later only against a measured cost that fits the budgets.

## Consequences

0 KB of web fonts. A brand font may be added later only against a measured cost that fits the budgets.

## Why

Accepted the recommendation.
