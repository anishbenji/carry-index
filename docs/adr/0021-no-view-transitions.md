# ADR-0021: No animated page transitions in Release 1

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "N6: Animated page transitions"

## Context

Cross-document view transitions are partial in Firefox and add time to every navigation.

## Decision

No cross-document view transitions in Release 1. Revisit later against the budgets, with reduced-motion support.

## Consequences

None in Release 1. Revisit later against the budgets, with reduced-motion support.

## Why

Accepted the recommendation.
