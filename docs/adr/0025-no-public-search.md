# ADR-0025: No search on the public site at launch

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "N8: Search on the public site"

## Context

Navigation and listing filters cover about 30 pages.

## Decision

No search on the public site at launch. Once articles exist, add an on-demand search that downloads nothing until the search box is opened.

## Consequences

No search in Release 1. Once articles exist, add an on-demand search that downloads nothing until the search box is opened.

## Why

Accepted the recommendation; navigation and listing filters cover about 30 pages.
