# ADR-0026: Public performance page from day one

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "A5: Public performance page"

## Context

Real-visitor figures are the strongest proof of the speed claim.

## Decision

`/performance` is public from day one, showing real-visitor figures, with an "early data" note until there are enough visits.

## Consequences

`/performance` is public at launch with an 'early data' note until there are enough visits. It is rebuilt from the first-party beacon's roll-ups and ships no script.

## Why

Accepted the recommendation; it is the strongest proof of the speed claim.
