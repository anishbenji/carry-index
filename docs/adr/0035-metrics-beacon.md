# ADR-0035: First-party metrics beacon from launch day

- **Status:** Accepted
- **Date:** 2026-11-25
- **Source:** `docs/brief/decisions.md`, entry "Metrics beacon timing"

## Context

Field data needs weeks to build, and the performance page needs it.

## Decision

The first-party metrics beacon ships in Release 1 and collects from launch day: one report per page view, no cookies, no stored IP addresses, collected fields listed on the about page, counted inside the 8 KB budget.

## Consequences

The beacon ships in Release 1: one report per page view, no cookies, no stored IP addresses, collected fields listed on the about page, counted inside the 8 KB budget.

## Why

Accepted the recommendation; field data needs weeks to build and the public performance page needs it.
